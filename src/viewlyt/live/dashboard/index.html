Import JSON

Format reference 
Array of probe objects, each one of:

open:
  { "kind": "open", "instruction": "Summarize the main themes.", "label"?: "Themes", "max_words"?: 60 }

classification:
  { "kind": "classification", "question": "What is the overall sentiment?",
    "categories": ["positive", "negative", "neutral"],
    "label"?: "Sentiment", "chart"?: "bars|columns|stacked|donut|lines|area|delta|gauge|heatmap|podium|violin|descartes" }

Notes:
  - "label" is optional and auto-generated from the text when omitted.
  - "kind" defaults to "open" when omitted.
  - "chart" applies only to classification probes (twelve types: bars, columns, stacked, donut, lines, area, delta, gauge, heatmap, podium, violin, descartes).
  - "descartes" plots a match-scoreline probe on a home x away Cartesian grid; its categories should be scorelines like "2x1", "1x0", "0x0" (picking it on an empty probe seeds a 0 to 3 grid for you).
  - any probe may carry "interval_s" (own refresh cadence, s) and "sample_n" (own sample size); 0 or omitted follows the global Window config.

Capture the chat

Open the live chat popout (youtube.com/live_chat?is_popout=1&v=…) in its own window, then start the capture there with one of the methods below. A small viewlyt badge appears in the popout showing connected, captured and sent counts.

Browser extension

Works in Chrome and Vivaldi, set and forget. Download the viewlyt extension (.zip), unzip it and load the folder from your browser’s Extensions page (Developer mode, then Load unpacked). It runs on every chat popout.

Bookmark

Set up once, no extension. Some browsers (Vivaldi) block bookmarklets, so use the extension or the console there. Right-click your bookmarks bar, choose Add page… (or open the Bookmark Manager), name it viewlyt and paste the code below as its URL. Then click the viewlyt bookmark on the chat popout.

Console

On the popout, open DevTools (F12), go to Console, paste the snippet and press Enter. If Chrome blocks the paste, type allow pasting there first.
